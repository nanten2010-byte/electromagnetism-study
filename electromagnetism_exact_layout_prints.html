スカラー関数の勾配 grad f の計算 (1) [No.001]

【演習問題】

次のスカラー関数 $f$ の勾配 $\mathrm{grad}\,f$ を求めよ。
(1) $f = e^x \sin y$

【公式・解法の要点】

勾配の定義：$\mathrm{grad}\,f = \nabla f = \left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}\right)$。各成分の偏微分を独立に計算する。

【ステップ詳細解説】
1. $x$ に関する偏微分：
$$\frac{\partial f}{\partial x} = \frac{\partial}{\partial x}(e^x \sin y) = e^x \sin y$$
2. $y$ に関する偏微分：
$$\frac{\partial f}{\partial y} = \frac{\partial}{\partial y}(e^x \sin y) = e^x \cos y$$
3. $z$ に関する偏微分：
$$\frac{\partial f}{\partial z} = 0$$
4. したがって勾配ベクトルは：
$$\nabla f = e^x \sin y \vec{i} + e^x \cos y \vec{j}$$
💡 試験直前チェック・指導ポイント
指数関数 $e^x$ と三角関数 $\sin y$ の偏微分で他変数を定数扱いすることを忘れないように。

スカラー関数の勾配 grad f の計算 (2) [No.002]

【演習問題】

次のスカラー関数 $f$ の勾配 $\mathrm{grad}\,f$ を求めよ。
(2) $f = (x^2+y^2+z^2)^2$

【公式・解法の要点】

合成関数の微分法：$u = x^2+y^2+z^2 = r^2$ と置くと $f = u^2$。$\nabla f = \frac{df}{du} \nabla u$ が成り立つ。

【ステップ詳細解説】
1. $u = x^2+y^2+z^2$ に対し $\nabla u = 2x\vec{i} + 2y\vec{j} + 2z\vec{k} = 2\vec{r}$。
2. 合成関数の偏微分：
$$\frac{\partial f}{\partial x} = 2(x^2+y^2+z^2) \cdot 2x = 4x(x^2+y^2+z^2)$$
$$\frac{\partial f}{\partial y} = 4y(x^2+y^2+z^2), \quad \frac{\partial f}{\partial z} = 4z(x^2+y^2+z^2)$$
3. したがって：
$$\nabla f = 4(x^2+y^2+z^2)(x\vec{i}+y\vec{j}+z\vec{k}) = 4 r^2 \vec{r}$$
💡 試験直前チェック・指導ポイント
球対称関数 $f(r)$ では $\nabla f(r) = f'(r)\frac{\vec{r}}{r}$ の公式を用いると一瞬で導出できる。

スカラー関数の勾配 grad f の計算 (3) [No.003]

【演習問題】

次のスカラー関数 $f$ の勾配 $\mathrm{grad}\,f$ を求めよ。
(3) $f = \frac{1}{2}\ln(x^2+y^2)$

【公式・解法の要点】

対数関数の偏微分：$\frac{\partial}{\partial x}\ln u = \frac{1}{u}\frac{\partial u}{\partial x}$。$2$次元極座標における半径 $r_{2D} = \sqrt{x^2+y^2}$ の電位分布に対応する。

【ステップ詳細解説】
1. $x$ 成分の偏微分：
$$\frac{\partial f}{\partial x} = \frac{1}{2} \cdot \frac{1}{x^2+y^2} \cdot 2x = \frac{x}{x^2+y^2}$$
2. $y$ 成分の偏微分：
$$\frac{\partial f}{\partial y} = \frac{1}{2} \cdot \frac{1}{x^2+y^2} \cdot 2y = \frac{y}{x^2+y^2}$$
3. $z$ 成分の偏微分：$\frac{\partial f}{\partial z} = 0$
4. したがって勾配ベクトルは：
$$\nabla f = \frac{x\vec{i}+y\vec{j}}{x^2+y^2}$$
💡 試験直前チェック・指導ポイント
直線電荷のつくる電位 $\phi \propto \ln r$ の勾配（電場）導出の基礎となる重要問題。

ベクトル関数の発散 div g の計算 (1) [No.004]

【演習問題】

次のベクトル関数 $\vec{g}$ の発散 $\mathrm{div}\,\vec{g}$ を求めよ。
(1) $\vec{g} = y^2 e^z \vec{i} + x^2 z^2 \vec{k}$

【公式・解法の要点】

発散の定義：$\mathrm{div}\,\vec{g} = \nabla\cdot\vec{g} = \frac{\partial g_x}{\partial x} + \frac{\partial g_y}{\partial y} + \frac{\partial g_z}{\partial z}$。

【ステップ詳細解説】
1. 各成分の偏微分を個別に計算する：
$$\frac{\partial g_x}{\partial x} = \frac{\partial}{\partial x}(y^2 e^z) = 0$$
$$\frac{\partial g_y}{\partial y} = \frac{\partial}{\partial y}(0) = 0$$
$$\frac{\partial g_z}{\partial z} = \frac{\partial}{\partial z}(x^2 z^2) = 2x^2 z$$
2. 和をとると：
$$\nabla\cdot\vec{g} = 0 + 0 + 2x^2 z = 2x^2 z$$
💡 試験直前チェック・指導ポイント
成分が存在しない部分（ここでは $y$ 成分）の偏微分は $0$ になる。

2. 足し合わせることで：
$$\nabla\cdot\vec{g} = -y e^{-xy} - z e^{-yz} - x e^{-zx}$$

ベクトル関数の回転 rot v の計算 (1) [No.007]

【演習問題】

次式で表されるベクトル $\vec{v}$ について $\mathrm{rot}\,\vec{v}$ を求めよ。
(1) $\vec{v} = z\vec{i} + x\vec{j} + y\vec{k}$

【公式・解法の要点】

回転の定義：$\nabla\times\vec{v} = \left( \frac{\partial v_z}{\partial y} - \frac{\partial v_y}{\partial z} \right)\vec{i} + \left( \frac{\partial v_x}{\partial z} - \frac{\partial v_z}{\partial x} \right)\vec{j} + \left( \frac{\partial v_y}{\partial x} - \frac{\partial v_x}{\partial y} \right)\vec{k}$。

【ステップ詳細解説】
1. 各回転成分を計算：
$$(\nabla\times\vec{v})_x = \frac{\partial (y)}{\partial y} - \frac{\partial (x)}{\partial z} = 1 - 0 = 1$$
$$(\nabla\times\vec{v})_y = \frac{\partial (z)}{\partial z} - \frac{\partial (y)}{\partial x} = 1 - 0 = 1$$
$$(\nabla\times\vec{v})_z = \frac{\partial (x)}{\partial x} - \frac{\partial (z)}{\partial y} = 1 - 0 = 1$$
2. したがって：
$$\mathrm{rot}\,\vec{v} = \vec{i} + \vec{j} + \vec{k}$$
💡 試験直前チェック・指導ポイント
空間全体で一様な渦（回転）が存在するベクトル場である。

ベクトル関数の回転 rot v の計算 (2) [No.008]

【演習問題】

次式で表されるベクトル $\vec{v}$ について $\mathrm{rot}\,\vec{v}$ を求めよ。
(2) $\vec{v} = x\vec{i} + yz\vec{j} - (x^2+z^2)\vec{k}$

【公式・解法の要点】

行列式表現を用い、巡回的にたすき掛け偏微分を行う。

【ステップ詳細解説】
1. 行列式による展開：
$$\nabla\times\vec{v} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ \partial_x & \partial_y & \partial_z \\ x & yz & -(x^2+z^2) \end{vmatrix}$$
2. 各成分：
$$x\text{成分}: \frac{\partial}{\partial y}(-(x^2+z^2)) - \frac{\partial}{\partial z}(yz) = 0 - y = -y$$
$$y\text{成分}: \frac{\partial}{\partial z}(x) - \frac{\partial}{\partial x}(-(x^2+z^2)) = 0 - (-2x) = 2x$$
$$z\text{成分}: \frac{\partial}{\partial x}(yz) - \frac{\partial}{\partial y}(x) = 0 - 0 = 0$$
3. したがって：
$$\mathrm{rot}\,\vec{v} = -y\vec{i} + 2x\vec{j}$$
💡 試験直前チェック・指導ポイント
$z$ 成分の回転が $0$ になる点を確認しておこう。

中心力場の回転 rot v の計算 (3) [No.009]

【演習問題】

次式で表されるベクトル $\vec{v}$ について $\mathrm{rot}\,\vec{v}$ を求めよ。
(3) $\vec{v} = (x\vec{i}+y\vec{j}+z\vec{k})(x^2+y^2+z^2)^{-3/2} = \frac{\vec{r}}{r^3}$

【公式・解法の要点】

中心力場 $\vec{v} = f(r)\vec{r}$ の回転は常にゼロベクトル $\vec{0}$（無回転場）となる。

【ステップ詳細解説】
1. ベクトルの各成分：$v_x = x r^{-3}, v_y = y r^{-3}, v_z = z r^{-3}$。
2. $z$ 成分の回転成分 $(\nabla\times\vec{v})_z$：
$$\frac{\partial v_y}{\partial x} = \frac{\partial}{\partial x}(y r^{-3}) = y (-3 r^{-4} \cdot \frac{x}{r}) = -3xy r^{-5}$$
$$\frac{\partial v_x}{\partial y} = \frac{\partial}{\partial y}(x r^{-3}) = x (-3 r^{-4} \cdot \frac{y}{r}) = -3xy r^{-5}$$
$$\implies (\nabla\times\vec{v})_z = -3xy r^{-5} - (-3xy r^{-5}) = 0$$
3. 同様にして $x, y$ 成分もすべて $0$ となる。
$$\mathrm{rot}\,\vec{v} = \vec{0}$$
💡 試験直前チェック・指導ポイント
点電荷のクーロン電場 $\vec{E} \propto \frac{\vec{r}}{r^3}$ が無回転（$\nabla\times\vec{E}=\vec{0}$）であり，静電ポテンシャルを持つ物理的理由の根拠である。

無限長直線電荷の電場厳密導出（微小要素積分） [No.040]

【演習問題】

線密度 $\lambda = 2\times 10^{-9}\,\mathrm{C/m}$ で均一に帯電した無限長直線から距離 $r$ 離れた点における電場の強さ $E(r)$ を求めよ。

【公式・解法の要点】

微小要素 $dx$ が点 $P$ につくる電場 $d\vec{E}$ の対称性を利用。軸に垂直な成分のみが生存する。

【ステップ詳細解説】
1. 微小電荷 $dq = \lambda dx$ の電場垂直成分：
$$dE_\perp = \frac{1}{4\pi\varepsilon_0} \frac{\lambda dx}{r^2+x^2} \cos\theta$$
2. 変数変換 $x = r \tan\theta \implies dx = \frac{r}{\cos^2\theta} d\theta$ を用いて全区間積分：
$$E(r) = \frac{\lambda}{4\pi\varepsilon_0 r} \int_{-\pi/2}^{\pi/2} \cos\theta d\theta = \frac{\lambda}{2\pi\varepsilon_0 r}$$
3. 数値を代入：
$$E(r) \approx \frac{36}{r} \,\mathrm{V/m}$$
💡 試験直前チェック・指導ポイント
ガウスの法則を用いても容易に導出できるが、直接積分法も重要な基盤技術である。

鏡像法（Method of Image Charges）による接地導体平面問題 [No.080]

【演習問題】

接地された無限大導体平面 $z=0$ から距離 $z=h \,\mathrm{m}$ の位置に点電荷 $+q$ がある。導体平面上に誘起される表面電荷密度 $\sigma(x,y)$ および点電荷が受ける引力 $F$ を求めよ。

【公式・解法の要点】

鏡像法の原理：$z=-h$ に置いた仮想の鏡像電荷 $-q$ による合成場として解く。

【ステップ詳細解説】
1. 空間 $z>0$ における電位 $\phi(x,y,z)$：
$$\phi(x,y,z) = \frac{q}{4\pi\varepsilon_0} \left( \frac{1}{\sqrt{x^2+y^2+(z-h)^2}} - \frac{1}{\sqrt{x^2+y^2+(z+h)^2}} \right)$$
2. 導体表面 $z=0$ 直上の電場 $E_z = -\left.\frac{\partial \phi}{\partial z}\right|_{z=0}$：
$$E_z(x,y,0) = -\frac{q h}{2\pi\varepsilon_0 (x^2+y^2+h^2)^{3/2}}$$
3. 表面電荷密度 $\sigma(x,y) = \varepsilon_0 E_z = -\frac{q h}{2\pi (x^2+y^2+h^2)^{3/2}}$
4. 静電引力 $F = \frac{1}{4\pi\varepsilon_0} \frac{q^2}{(2h)^2} = \frac{q^2}{16\pi\varepsilon_0 h^2}$$
💡 試験直前チェック・指導ポイント
全誘起電荷を面積分すると $\iint \sigma dxdy = -q$ となり、電束保存と一致する。

第12回 演習とレポート

誘電体境界条件と電界の屈折の法則 [No.120]

【演習問題】

誘電率 $\varepsilon_1$ の媒質1と $\varepsilon_2$ の媒質2の境界において電荷が存在しない。媒質1における電界が法線と角度 $\theta_1$ をなすとき、媒質2における屈折角 $\theta_2$ および電場 $E_2$ を求めよ。

【公式・解法の要点】

境界条件：(1) 電界の接線成分の連続性 $E_{1t} = E_{2t} \implies E_1 \sin\theta_1 = E_2 \sin\theta_2$。(2) 電束密度の法線成分の連続性 $D_{1n} = D_{2n} \implies \varepsilon_1 E_1 \cos\theta_1 = \varepsilon_2 E_2 \cos\theta_2$。

【ステップ詳細解説】
1. 2つの境界条件の比をとる：
$$\frac{E_1 \sin\theta_1}{\varepsilon_1 E_1 \cos\theta_1} = \frac{E_2 \sin\theta_2}{\varepsilon_2 E_2 \cos\theta_2} \implies \frac{\tan\theta_1}{\varepsilon_1} = \frac{\tan\theta_2}{\varepsilon_2}$$
2. 整理すると電界の屈折の法則を得る：
$$\frac{\tan\theta_1}{\tan\theta_2} = \frac{\varepsilon_1}{\varepsilon_2}$$
3. 媒質2の電場 $E_2$ の成分合成：
$$E_2 = \sqrt{E_{2t}^2 + E_{2n}^2} = \sqrt{(E_1\sin\theta_1)^2 + \left(\frac{\varepsilon_1}{\varepsilon_2} E_1\cos\theta_1\right)^2} = E_1 \sqrt{\sin^2\theta_1 + \left(\frac{\varepsilon_1}{\varepsilon_2}\right)^2 \cos^2\theta_1}$$
💡 試験直前チェック・指導ポイント
光の屈折の法則（スネルの法則）とは比の上下関係が逆（誘電率が大きい媒質ほど法線から離れる）になる点に注意。
