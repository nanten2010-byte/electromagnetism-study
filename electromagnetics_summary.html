第1回：ベクトル解析の基礎（勾配・発散・回転）

問題 1. スカラー場の最急上り坂ベクトル（勾配 $\text{grad } f$）

次のスカラー関数 $f$ の勾配 $\nabla f$ を求めよ。

1) $f = e^x \sin y$     2) $f = (x^2+y^2+z^2)^2$     3) $f = \frac{1}{2}\ln(x^2+y^2)$

💡 物理的・直感的な意味の再確認

「標高」や「温度・電位」などのスカラー分布に対し、その場所から「どの向きに移動すれば最も急激に値が上がるか（最急傾斜方向）」と「その坂の急傾斜度（傾き）」を矢印（ベクトル）として取り出す操作です。

【ステップ解説】
ステップ 1：各方向の微分（各軸沿いの坂の傾き）を求める

$\nabla f = \left( \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z} \right)$

ステップ 2：計算を実行する

1) $\frac{\partial f}{\partial x} = e^x \sin y, \ \frac{\partial f}{\partial y} = e^x \cos y \implies \mathbf{\nabla f = e^x \sin y \vec{i} + e^x \cos y \vec{j}}$

2) 合成関数の微分より $\mathbf{\nabla f = 4(x^2+y^2+z^2)(x\vec{i} + y\vec{j} + z\vec{k})}$

3) $\frac{\partial f}{\partial x} = \frac{x}{x^2+y^2} \implies \mathbf{\nabla f = \frac{1}{x^2+y^2}(x\vec{i} + y\vec{j})}$

問題 2. ベクトル場の湧き出し密度（発散 $\text{div } \vec{g}$）

次のベクトル関数 $\vec{g}$ の発散 $\nabla \cdot \vec{g}$ を求めよ。

1) $\vec{g} = y^2 e^z \vec{i} + x^2 z^2 \vec{k}$     2) $\vec{g} = x^2 \vec{i} + y^2 \vec{j} + z^2 \vec{k}$     3) $\vec{g} = e^{-xy}\vec{i} + e^{-yz}\vec{j} + e^{-zx}\vec{k}$

💡 物理的・直感的な意味の再確認

微小なサイコロ（空間の点）を置いたとき、そこから水や電場などのベクトルが「新しく湧き出しているか（正）」または「吸い込まれているか（負）」の正味の増減量をスカラー値として測る計算です。

【ステップ解説】
ステップ 1：各成分の偏微分を足し合わせる

$\nabla \cdot \vec{g} = \frac{\partial g_x}{\partial x} + \frac{\partial g_y}{\partial y} + \frac{\partial g_z}{\partial z}$

ステップ 2：計算を実行する

1) $0 + 0 + 2x^2 z = \mathbf{2x^2 z}$

2) $2x + 2y + 2z = \mathbf{2(x+y+z)}$

3) $\mathbf{-y e^{-xy} - z e^{-yz} - x e^{-zx}}$

問題 3. 流体の中の「微小風車の回りやすさ」（回転 $\text{rot } \vec{v}$）

次式で表されるベクトル $\vec{v}$ について $\text{rot } \vec{v}$ を求めよ。

1) $\vec{v} = z\vec{i}+x\vec{j}+y\vec{k}$     2) $\vec{v} = x\vec{i}+yz\vec{j}-(x^2+z^2)\vec{k}$     3) $\vec{v} = \frac{\vec{r}}{r^3}$

💡 物理的・直感的な意味の再確認

流体の中に置いた超小型の水車が、流速の「場所によるズレ（シアー）」によってくるくる回転するかどうか、その「回転軸の向き」と「回転の激しさ（角速度）」を示すベクトルを求めます。

【ステップ解説】
ステップ 1：行列式による回転の計算

$\nabla \times \vec{v} = \det \begin{pmatrix} \vec{i} & \vec{j} & \vec{k} \\ \partial_x & \partial_y & \partial_z \\ v_x & v_y & v_z \end{pmatrix}$

ステップ 2：計算を実行する

1) $(1-0)\vec{i} + (1-0)\vec{j} + (1-0)\vec{k} = \mathbf{\vec{i} + \vec{j} + \vec{k}}$ （対角線を軸に回転する一様な渦）

2) $(0-y)\vec{i} - (-2x-0)\vec{j} + (0-0)\vec{k} = \mathbf{-y\vec{i} + 2x\vec{j}}$

3) 放射状の場（中心力場）は渦を作らないため $\mathbf{\vec{0}}$

問題 4. 中心からの距離 $r$ の勾配公式

$\vec{r} = x\vec{i}+y\vec{j}+z\vec{k}, r = |\vec{r}|$ とするとき： 1) $\nabla r$, 2) $\nabla \frac{1}{r}$, 3) $\nabla r^n$, 4) $\nabla \ln r$ を求めよ。

💡 物理的・直感的な意味の再確認

原点からの距離 $r$ だけに依存する場の球対称な変化率を求める公式です。勾配の向きは常に「原点から外に向かう放射方向の単位ベクトル $\vec{r}/r$」になります。

【ステップ解説】
ステップ 1：基本公式 $\nabla r = \frac{\vec{r}}{r}$ を使う

合成関数の微分：$\nabla f(r) = f'(r) \nabla r = f'(r) \frac{\vec{r}}{r}$

ステップ 2：計算結果

1) $\mathbf{\frac{\vec{r}}{r}}$ （中心から外に向かう単位ベクトル）

2) $-\frac{1}{r^2}\frac{\vec{r}}{r} = \mathbf{-\frac{\vec{r}}{r^3}}$ （点電荷の電場 $E = -\nabla \phi$ の基礎）

3) $\mathbf{n r^{n-2} \vec{r}}$

4) $\mathbf{\frac{\vec{r}}{r^2}}$

問題 5. 逆二乗則ベクトルの発散と点源の物理

1) $\nabla \cdot (\vec{r}/r)$     2) $\nabla \cdot (\vec{r}/r^3)$ を求めよ。

💡 物理的・直感的な意味の再確認

点電荷がつくる電場 $\vec{E} \propto \vec{r}/r^3$ は「電荷が存在する原点以外のあらゆる場所で湧き出しゼロ ($\text{div }\vec{E} = 0$)」になるという静電磁気学の根本的性質を示しています。

【ステップ解説】
ステップ 1：積の微分の公式展開

$\nabla \cdot (f \vec{A}) = (\nabla f)\cdot \vec{A} + f (\nabla \cdot \vec{A})$

ステップ 2：代入して計算

1) $\nabla(\frac{1}{r})\cdot\vec{r} + \frac{1}{r}(\nabla\cdot\vec{r}) = -\frac{\vec{r}}{r^3}\cdot\vec{r} + \frac{3}{r} = -\frac{1}{r} + \frac{3}{r} = \mathbf{\frac{2}{r}}$

2) $\nabla(r^{-3})\cdot\vec{r} + r^{-3}(3) = -3r^{-5}(\vec{r}\cdot\vec{r}) + 3r^{-3} = -3r^{-3} + 3r^{-3} = \mathbf{0}$ （原点を除く空間で正味の湧き出しゼロ！）

第2回：線積分

問題 1. 円周上の壁の面積を求める

$$\int_C \varphi \, ds \quad \left(\varphi = 2xy^2, \quad C : \vec{r}(s) = \cos s \vec{i} + \sin s \vec{j} \quad (0 \le s \le \pi/2)\right)$$

💡 物理的・直感的な意味の再確認

半径 1 の円弧（第1象限の 1/4 の円）というカーブの上に建てられた、高さ $2xy^2$ の「曲がった壁」の表面積を求める計算です。

【ステップ解説】
ステップ 1：コース上の位置と微小長さを表す

$x = \cos s, \ y = \sin s$

移動距離の微小変化：$ds = 1 \, ds$ （単位円周に沿って進む長さそのまま）

ステップ 2：壁の高さを角度 $s$ の式にする

壁の高さ $\varphi = 2xy^2 = 2 \cos s \sin^2 s$

ステップ 3：スタート（$s=0$）からゴール（$s=\pi/2$）まで合算する

$$\int_0^{\pi/2} 2 \cos s \sin^2 s \, ds = \left[ \frac{2}{3} \sin^3 s \right]_0^{\pi/2} = \mathbf{\frac{2}{3}}$$

問題 2. 直線ルート上の値の累積和

$$\int_C xy^3 ds \quad \left(\text{直線 } y = 2x, \ A(-1, -2, 0) \to B(1, 2, 0)\right)$$

💡 物理的・直感的な意味の再確認

$A(-1,-2)$ から $B(1,2)$ へのまっすぐな斜めの道を進むとき、各地点での「値（$x \cdot y^3$）」に道のり $ds$ を掛けながら足し合わせる計算です。

【ステップ解説】
ステップ 1：道のりを媒介変数 $t$ で表す

$x = t, \ y = 2t \ (-1 \le t \le 1)$

斜めに進むため微小距離 $ds = \sqrt{(dx)^2 + (dy)^2} = \sqrt{1^2 + 2^2} dt = \sqrt{5} dt$

ステップ 2：コース上の値を $t$ で表す

$xy^3 = t \cdot (2t)^3 = 8t^4$

ステップ 3：積算する

$$\int_{-1}^1 (8t^4) \cdot \sqrt{5} dt = 8\sqrt{5} \left[ \frac{t^5}{5} \right]_{-1}^1 = \mathbf{\frac{16\sqrt{5}}{5}}$$

問題 4. らせん階段コースでの場の影響量

$$\varphi = 2xz, \quad C : (\cos t, \sin t, t) \quad (0 \le t \le \pi)$$

💡 物理的・直感的な意味の再確認

上に向かってグルッと登る「らせん階段」を進みながら、その場の値（$2 \times x \times z$）を全行程で積算する計算です。

【ステップ解説】
ステップ 1：各成分と微小道のり $ds$ を出す

$ds = \sqrt{(-\sin t)^2 + (\cos t)^2 + 1^2} dt = \sqrt{2} dt$

ステップ 2：コース上の値と部分積分

$\varphi = 2t\cos t$

$$\int_0^\pi 2t \cos t \cdot \sqrt{2} dt = 2\sqrt{2} [t \sin t + \cos t]_0^\pi = 2\sqrt{2}(-1 - 1) = \mathbf{-4\sqrt{2}}$$

問題 7. 空間を移動するときに「力がした仕事」

$$\int_C \vec{F} \cdot d\vec{r} \quad \left(\vec{F} = (2x, \sqrt{y}, 2z), \quad C : (t, t^2, 1-t) \quad (0 \le t \le 1)\right)$$

💡 物理的・直感的な意味の再確認

力（風など）が吹いている空間の中をコース $C$ に沿って動いたとき、進行方向と重なる力（内積）だけを取り出して、スタートからゴールまでに得られた「エネルギー（仕事）」を計算します。

【ステップ解説】
ステップ 1：移動ベクトル $d\vec{r}$ と力 $\vec{F}$ を $t$ に揃える

$d\vec{r} = (1, 2t, -1) dt$, $\vec{F} = (2t, t, 2-2t)$

ステップ 2：進行方向と重なる力（内積）を計算する

$\vec{F} \cdot d\vec{r} = (2t \cdot 1 + t \cdot 2t + (2-2t)(-1)) dt = (2t^2 + 4t - 2) dt$

ステップ 3：仕事の合計を出す

$$\int_0^1 (2t^2 + 4t - 2) dt = \left[ \frac{2}{3}t^3 + 2t^2 - 2t \right]_0^1 = \mathbf{\frac{2}{3}}$$

問題 9. 周回コースで受けるトータルの推進力（循環）

$$\int_C \vec{F} \cdot d\vec{r} \quad (\text{半径 3 の円周 } C : x = 3\cos t, y = 3\sin t)$$

💡 物理的・直感的な意味の再確認

円形コースをぐるっと1周したときに、流れや風から「トータルでどれくらい追い風（推進力）を受けたか（循環）」を求める計算です。

【ステップ解説】
ステップ 1：内積を計算して整理する

$\vec{F} \cdot d\vec{r} = 9(1 - \sin t \cos t) dt$

ステップ 2：1周分（$0 \to 2\pi$）合算する

$\sin t \cos t$ （波の振動成分）は1周で相殺されて 0。定数 9 のみ残り：

$$9 \int_0^{2\pi} 1 dt = 9 \times 2\pi = \mathbf{18\pi}$$

第4回：ベクトル解析の定理（ガウス＆ストークス）

問題 3. 球面を突き抜ける全体の湧き出し量（ガウスの定理）

原点を中心とする半径 $a$ の球面を $S$ とする。 $\vec{A} = x^3\vec{i}+y^3\vec{j}+z^3\vec{k}$ に対し $\int_S \vec{A} \cdot d\vec{S}$ を求めよ。

💡 物理的・直感的な意味の再確認

球体の表面（皮）から外に吹き出していく水や電場などの「表面からの湧き出し総量」は、球体の中身（実）全体で湧き出している「源の合計」と完全に一致するというガウスの発散定理の直感的応用です。

【ステップ解説】
ステップ 1：中身全体の湧き出し密度 $\nabla \cdot \vec{A}$ を計算

$\nabla \cdot \vec{A} = 3x^2 + 3y^2 + 3z^2 = 3r^2$

ステップ 2：球体全体で体積積分（極座標）を実行する

$$\iiint_V 3r^2 dv = \int_0^{2\pi} d\phi \int_0^\pi \sin\theta d\theta \int_0^a 3r^4 dr = 2\pi \cdot 2 \cdot \frac{3}{5}a^5 = \mathbf{\frac{12}{5}\pi a^5}$$

問題 6. 周回運動の推進力と膜の上の「渦の合計」（ストークスの定理）

円 $C: x^2+y^2=4$ に沿う $\vec{A} = (x^2+y)\vec{i} + (x^2+2z)\vec{j} + 2y\vec{k}$ の線積分をストークスの定理で求めよ。

💡 物理的・直感的な意味の再確認

輪っかをぐるりと1周進む間に受ける推進力（周回積分）は、その輪っかに張った「シャボン玉の膜（面）」の上で巻き起こっている微小な「渦（回転 $\text{rot}$）」を全域で集計したものと等しくなります。

【ステップ解説】
ステップ 1：膜の上で渦の強さ $\nabla \times \vec{A}$ を測る

$\nabla \times \vec{A} = (2-2)\vec{i} + 0\vec{j} + (2x-1)\vec{k} = (2x-1)\vec{k}$

ステップ 2：円盤面 $D$ 全体で渦を集計する

$$\iint_D (2x-1) dx dy = 2 \iint x dx dy - \iint 1 dx dy = 0 - \pi(2^2) = \mathbf{-4\pi}$$

第5回：クーロンの法則と電荷分布の電場

問題 1. 地球の巨視的電荷とミクロな電子数

地球の全体電荷 $-4.6 \times 10^5\text{ C}$ に相当する電子数と，それが何 ml の水に含まれるか求めよ。

💡 物理的・直感的な意味の再確認

地球規模の巨大な静電気（$-4.6 \times 10^5\text{ C}$）であっても、ミクロな視点で見るとわずかコップ半分の水（$8.8\text{ ml}$）に含まれる電子数と等しいという、電気素量の小ささと物質中の巨大な電荷密度を直感する計算です。

【ステップ解説】
ステップ 1：電荷を電気素量 $e$ で割って個数を出す

$N = \frac{4.6 \times 10^5}{1.6 \times 10^{-19}} = \mathbf{2.9 \times 10^{24}\text{ 個}}$

ステップ 2：水 $1\text{ ml} = 1\text{ g}$ 中の電子数と比較する

水 $1\text{ g}$ は $\frac{1}{18}\text{ mol}$。電子数は $\frac{1}{18} \times 6.0 \times 10^{23} \times 10 = 3.3 \times 10^{23}\text{ 個/ml}$

必要量 $= \frac{2.9 \times 10^{24}}{3.3 \times 10^{23}} \approx \mathbf{8.8\text{ ml}}$

問題 2. クーロン力 vs 万有引力の圧倒的差

距離 $1.0 \times 10^{-15}\text{ m}$ 離れた 2 つの陽子間にはたらくクーロン力と万有引力を比較せよ。

💡 物理的・直感的な意味の再確認

微視的な世界（原子核のスケール）では、質量による引力（万有引力）は電気的な退け合い（クーロン力）に比べて無に等しいほど弱く、$10^{36}$ 倍（1000溝倍！）という圧倒的な差で静電気が支配していることを実感します。

【ステップ解説】
ステップ 1：それぞれの力を計算

クーロン力：$F_C = \frac{1}{4\pi\varepsilon_0} \frac{e^2}{r^2} = 9.0 \times 10^9 \times \frac{(1.6\times 10^{-19})^2}{(1.0\times 10^{-15})^2} = \mathbf{2.3 \times 10^2\text{ N}}$

万有引力：$F_G = G \frac{m_p^2}{r^2} = 6.7 \times 10^{-11} \times \frac{(1.7\times 10^{-27})^2}{(1.0\times 10^{-15})^2} = \mathbf{1.9 \times 10^{-34}\text{ N}}$

ステップ 2：比率を出す

$$\frac{F_C}{F_G} = \frac{2.3 \times 10^2}{1.9 \times 10^{-34}} \approx \mathbf{1.2 \times 10^{36}\text{ 倍}}$$

第6回：ガウスの法則とその応用

問題 7. 正電荷の地球（球体）の中で躍動する「単振動」

正電荷 $+Q$ が一様に詰まった半径 $R$ の球の中に，負電荷 $-q$（質量 $m$）の質点を置いたときの単振動の周期 $T$ を求めよ。

💡 物理的・直感的な意味の再確認

電荷が詰まった球の内部では、中心からの距離 $r$ に比例して引き戻される力（フックの法則と同型の復元力）を受けるため、質点は中心をはさんで綺麗なバネのような単振動（往復運動）を続けます。

【ステップ解説】
ステップ 1：ガウスの法則で球内部の電場 $E(r)$ を出す

$E(r) \cdot 4\pi r^2 = \frac{Q (r^3/R^3)}{\varepsilon_0} \implies E(r) = \frac{Q r}{4\pi\varepsilon_0 R^3}$

ステップ 2：運動方程式を立てる

$$m \frac{d^2 r}{dt^2} = -q E(r) = -\left( \frac{qQ}{4\pi\varepsilon_0 R^3} \right) r$$

ステップ 3：単振動の周期 $T$ を求める

角振動数 $\omega = \sqrt{\frac{qQ}{4\pi\varepsilon_0 m R^3}}$ より：

$$T = \frac{2\pi}{\omega} = \mathbf{2\pi \sqrt{\frac{4\pi\varepsilon_0 m R^3}{qQ}}}$$

第9回：定常電流・オームの法則・Drudeモデル

問題 2. 銅線の中を進む電子の「カメより遅い」平均速度

断面積 $1\text{ mm}^2$ の導線に $1\text{ A}$ の電流が流れているとき，自由電子（密度 $n = 5.8 \times 10^{28}\text{ m}^{-3}$）の平均ドリフト速度 $\bar{v}$ を求めよ。

💡 物理的・直感的な意味の再確認

スイッチを入れた瞬間に電磁波信号は光速で伝わりますが、導線の中の個々の電子自体は「1秒にわずか 0.1 ミリ（秒速 $0.11\text{ mm/s}$）」という、カタツムリよりも圧倒的にスローペースで這うようにしか進んでいないという物理的直感です。

【ステップ解説】
ステップ 1：電流密度 $j$ を計算する

$j = \frac{I}{S} = \frac{1\text{ A}}{10^{-6}\text{ m}^2} = 10^6\text{ A/m}^2$

ステップ 2：$j = n e \bar{v}$ より平均速度 $\bar{v}$ を算出

$$\bar{v} = \frac{j}{n e} = \frac{10^6}{5.8 \times 10^{28} \times 1.6 \times 10^{-19}} = 1.07 \times 10^{-4}\text{ m/s} \approx \mathbf{0.11\text{ mm/s}}$$

問題 6. 微視的衝突（Drudeモデル）とオームの法則の誕生

電場 $\vec{E}$ をかけた金属内で，電子が平均自由時間 $\tau$ ごとに原子と衝突を繰り返す微視的モデル（Drudeモデル）から，電気伝導率 $\sigma = \frac{ne^2\tau}{m}$ を導出せよ。

💡 物理的・直感的な意味の再確認

電子は電場から加速されますが、障害物（金属の原子）にぶつかって衝撃で速度がリセット（熱に変化＝ジュール熱）されます。この「加速」と「衝突リセット」の繰り返しによって平均速度が電場に比例し、マクロなオームの法則が生まれます。

【ステップ解説】
ステップ 1：運動方程式から時間 $\tau$ 後の到達速度を出す

$m \vec{a} = -e\vec{E} \implies \vec{a} = -\frac{e\vec{E}}{m}$。時間 $\tau$ の平均到達速度 $\vec{\bar{v}} = -\frac{e\tau}{m}\vec{E}$

ステップ 2：電流密度 $\vec{j}$ に代入する

$$\vec{j} = -n e \vec{\bar{v}} = \left( \frac{n e^2 \tau}{m} \right) \vec{E}$$

第12回：誘電体の境界条件と屈折法則

問題 4. 光のように折れ曲がる「電場の屈折法則」

誘電率 $\varepsilon_1, \varepsilon_2$ の境界における電場の屈折法則 $\frac{\tan \theta_1}{\tan \theta_2} = \frac{\varepsilon_1}{\varepsilon_2}$ を導出せよ。

💡 物理的・直感的な意味の再確認

光が空気から水に入るときに屈折するように、電気力線（電場）も誘電率の異なる物質の境界を越える際、境界面に沿う成分（接線）と垂直な成分（法線）の連続性の違いによって屈折角が変化します。

【ステップ解説】
ステップ 1：電界の接線成分の連続性（$\text{rot }\vec{E} = 0$ より）

$E_{1t} = E_{2t} \implies E_1 \sin \theta_1 = E_2 \sin \theta_2 \quad \text{--- (1)}$

ステップ 2：電束密度の法線成分の連続性（$\text{div }\vec{D} = 0$ より）

$D_{1n} = D_{2n} \implies \varepsilon_1 E_1 \cos \theta_1 = \varepsilon_2 E_2 \cos \theta_2 \quad \text{--- (2)}$

ステップ 3：式(1)を式(2)で割って屈折法則を得る

$$\frac{E_1 \sin \theta_1}{\varepsilon_1 E_1 \cos \theta_1} = \frac{E_2 \sin \theta_2}{\varepsilon_2 E_2 \cos \theta_2} \implies \mathbf{\frac{\tan \theta_1}{\tan \theta_2} = \frac{\varepsilon_1}{\varepsilon_2}}$$
