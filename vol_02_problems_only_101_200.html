スカラー場の線積分 \(\int_C \phi ds\) の計算演習 [No.101]

【演習問題】

曲線 $C: \vec{r}(t) = \cos t \vec{i} + \sin t \vec{j} + 3t \vec{k} \quad (0 \le t \le \pi)$ に沿うスカラー場 $\phi = 3z$ の線積分 $\int_C \phi ds$ を求めよ。

【公式・解法の要点】

線要素 $ds = \left|\frac{d\vec{r}}{dt}\right| dt = \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2 + \left(\frac{dz}{dt}\right)^2} dt$。

【ステップ詳細解説】
1. 速度ベクトルとその大きさを計算：
$$\frac{d\vec{r}}{dt} = -\sin t \vec{i} + \cos t \vec{j} + 3 \vec{k}$$
$$ds = \sqrt{(-\sin t)^2 + (\cos t)^2 + 9} dt = \sqrt{10} dt$$
2. $\phi = 3z = 9t$ を代入して線積分を実行：
$$\int_C \phi ds = \int_0^{\pi} (9t) \sqrt{10} dt = 9\sqrt{10} \left[ \frac{t^2}{2} \right]_0^{\pi} = \frac{9\pi^2\sqrt{10}}{2}$$
💡 試験直前チェック・指導ポイント
弧長要素 $ds$ の根号計算を焦らず正確に行うこと。
