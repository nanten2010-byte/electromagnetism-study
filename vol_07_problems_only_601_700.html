静電ポテンシャル \(\phi\) と電気双極子モーメント演習 [No.601]

【演習問題】

原点に位置する電気双極子 $\vec{p} = p \vec{k}$ （$p = 2\times 10^{-30} \,\mathrm{C\cdot m}$）がつくる静電ポテンシャル $\phi(r,\theta)$ および極座標における電場成分 $E_r, E_\theta$ を導出せよ。

【公式・解法の要点】

双極子ポテンシャル：$\phi(r,\theta) = \frac{p \cos\theta}{4\pi\varepsilon_0 r^2}$。

【ステップ詳細解説】
1. 電位の偏微分：
$$E_r = -\frac{\partial \phi}{\partial r} = \frac{2p \cos\theta}{4\pi\varepsilon_0 r^3}, \quad E_\theta = -\frac{1}{r} \frac{\partial \phi}{\partial \theta} = \frac{p \sin\theta}{4\pi\varepsilon_0 r^3}$$
2. 電場の大きさ：
$$|\vec{E}| = \sqrt{E_r^2 + E_\theta^2} = \frac{p}{4\pi\varepsilon_0 r^3} \sqrt{3\cos^2\theta + 1}$$
💡 試験直前チェック・指導ポイント
距離 $r$ の 3 乗に反比例して急激に減衰する点が単一電荷（$1/r^2$）との違いである。

【公式・解法の要点】

双極子ポテンシャル：$\phi(r,\theta) = \frac{p \cos\theta}{4\pi\varepsilon_0 r^2}$。

$$|\vec{E}| = \sqrt{E_r^2 + E_\theta^2} = \frac{p}{4\pi\varepsilon_0 r^3} \sqrt{3\cos^2\theta + 1}$$

双極子ポテンシャル：$\phi(r,\theta) = \frac{p \cos\theta}{4\pi\varepsilon_0 r^2}$。

【ステップ詳細解説】
1. 電位の偏微分：
$$E_r = -\frac{\partial \phi}{\partial r} = \frac{2p \cos\theta}{4\pi\varepsilon_0 r^3}, \quad E_\theta = -\frac{1}{r} \frac{\partial \phi}{\partial \theta} = \frac{p \sin\theta}{4\pi\varepsilon_0 r^3}$$
2. 電場の大きさ：
$$|\vec{E}| = \sqrt{E_r^2 + E_\theta^2} = \frac{p}{4\pi\varepsilon_0 r^3} \sqrt{3\cos^2\theta + 1}$$

距離 $r$ の 3 乗に反比例して急激に減衰する点が単一電荷（$1/r^2$）との違いである。
