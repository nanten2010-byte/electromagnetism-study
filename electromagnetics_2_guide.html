スカラー場・ベクトル場の線積分（全10問題・14小問）の解説と解答

0. 線積分の基本公式まとめ 必須公式

第2回で扱うスカラー場およびベクトル場の線積分の公式一覧です。

1. 線素 $ds$: 媒介変数 $t$ による表示 $\vec{r}(t) = (x(t), y(t), z(t))$ のとき
$$ds = \left| \frac{d\vec{r}}{dt} \right| dt = \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2 + \left(\frac{dz}{dt}\right)^2} dt$$

2. スカラー場の線積分: $\int_C \phi \, ds = \int_{t_1}^{t_2} \phi(x(t), y(t), z(t)) \left| \frac{d\vec{r}}{dt} \right| dt$

3. ベクトル場の線積分 (仕事・循環):
$$\int_C \vec{F} \cdot d\vec{r} = \int_{t_1}^{t_2} \left( F_x \frac{dx}{dt} + F_y \frac{dy}{dt} + F_z \frac{dz}{dt} \right) dt = \int_C (F_x dx + F_y dy + F_z dz)$$

問題 1. 弧長 $s$ による円弧上の線積分 問1
問題 1 曲線 $C$ が弧の長さ $s$ によって次式で表されるとき，円弧の上で $\phi = 2xy^2$ を積分せよ． $$\vec{r}(s) = \cos s \, \vec{i} + \sin s \, \vec{j} \quad \left(0 \leq s \leq \frac{\pi}{2}\right)$$

$x = \cos s, \; y = \sin s \implies \phi(s) = 2 \cos s \sin^2 s$

✏️ 置換積分の途中計算を見る
$\int_0^{\pi/2} 2 \cos s \sin^2 s \, ds$ において $u = \sin s$ と置くと $du = \cos s \, ds$。
積分範囲は $s: 0 \to \pi/2 \implies u: 0 \to 1$。
$$\int_0^1 2u^2 du = \left[ \frac{2}{3}u^3 \right]_0^1 = \frac{2}{3}$$
【解答】 $\frac{2}{3}$
問題 2. 直線分に沿うスカラー線積分 問2
問題 2 $C$ が $xy$ 平面上の直線 $y = 2x$ を $\mathrm{A}(-1,-2,0)$ から $\mathrm{B}(1,2,0)$ まで区切った線分であるとき，$\int_C xy^3 \, ds$ を求めよ．

パラメータ $x = t \quad (-1 \leq t \leq 1) \implies y = 2t, \; z = 0$

線素: $ds = \sqrt{1^2 + 2^2 + 0^2} \, dt = \sqrt{5} \, dt$、被積分関数: $xy^3 = t(2t)^3 = 8t^4$

✏️ 積分の途中計算を見る
$$\int_C xy^3 \, ds = \int_{-1}^1 (8t^4) \sqrt{5} \, dt = 8\sqrt{5} \left[ \frac{t^5}{5} \right]_{-1}^1 = 8\sqrt{5} \left( \frac{1}{5} - \left(-\frac{1}{5}\right) \right) = \frac{16\sqrt{5}}{5}$$
【解答】 $\frac{16\sqrt{5}}{5}$
問題 3. 線分および折れ線に沿う線積分 問3
問題 3 全体指示 スカラー場 $\phi = x^2 + y^2 + z^2$ について，下記を計算せよ．
1) $\mathrm{P}(1, -1, 0)$ と $\mathrm{Q}(2, 1, 2)$ を結ぶ線分 $\mathrm{PQ}$ に沿った線積分 $\int_{\mathrm{PQ}} \phi \, ds$

線分 $\mathrm{PQ}$ のパラメータ表示: $\vec{r}(t) = (1+t, \, -1+2t, \, 2t) \quad (0 \leq t \leq 1)$

$ds = \sqrt{1^2 + 2^2 + 2^2} \, dt = 3dt$、 $\phi(t) = (1+t)^2 + (-1+2t)^2 + (2t)^2 = 9t^2 - 2t + 2$

✏️ 定積分の詳細な計算プロセスを見る
$$\int_{\mathrm{PQ}} \phi \, ds = \int_0^1 (9t^2 - 2t + 2) \cdot 3 \, dt = 3 \left[ 3t^3 - t^2 + 2t \right]_0^1 = 3(3 - 1 + 2) = 12$$
【解答】 $12$
2) 1) において、原点 $\mathrm{O}$ を経由した折れ線 $\mathrm{PO}, \mathrm{OQ}$ に沿った線積分 $\int_{\mathrm{PO+OQ}} \phi \, ds$

・線分 $\mathrm{PO}$: $\vec{r}(t) = (1-t, \, -(1-t), \, 0) \implies ds = \sqrt{2}dt, \; \phi = 2(1-t)^2 \implies \int = \frac{2\sqrt{2}}{3}$

・線分 $\mathrm{OQ}$: $\vec{r}(u) = (2u, \, u, \, 2u) \implies ds = 3du, \; \phi = 9u^2 \implies \int = 9$

【解答】 $\frac{2\sqrt{2} + 27}{3} \quad \left( = \frac{2\sqrt{2}}{3} + 9 \right)$
問題 4. つるまき線に沿う線積分 問4
問題 4 スカラー場 $\phi = 2xz$ について，曲線 $C: \vec{r}(t) = \cos t \, \vec{i} + \sin t \, \vec{j} + t \, \vec{k}, \; (0 \leq t \leq \pi)$ に沿った線積分 $\int_C \phi \, ds$ を求めよ．

$\phi(t) = 2t \cos t$, \; $ds = \sqrt{(-\sin t)^2 + (\cos t)^2 + 1^2} \, dt = \sqrt{2} \, dt$

✏️ 部分積分の計算展開を見る
$$\int_C \phi \, ds = 2\sqrt{2} \int_0^\pi t \cos t \, dt$$ 部分積分法: $\int t \cos t \, dt = t \sin t - \int \sin t \, dt = t \sin t + \cos t$
$[t \sin t + \cos t]_0^\pi = (\pi \cdot 0 + (-1)) - (0 + 1) = -2$
したがって、積分値 $= 2\sqrt{2} \times (-2) = -4\sqrt{2}$
【解答】 $-4\sqrt{2}$
問題 5. $\int \phi dt$ と $\int \phi ds$ の計算 問5
問題 5 全体指示 スカラー場 $\phi = x^2 + y^2 + z^2$ について，曲線 $C: \vec{r} = 4\cos t \, \vec{i} + 4\sin t \, \vec{j} + 3t \, \vec{k} \quad (0 \leq t \leq \pi)$ に沿った次の線積分を求めよ．

被積分スカラー関数: $\phi(t) = (4\cos t)^2 + (4\sin t)^2 + (3t)^2 = 16 + 9t^2$

3) $\int_C \phi \, dt$

$\int_0^\pi (16 + 9t^2) \, dt = \left[ 16t + 3t^3 \right]_0^\pi = 16\pi + 3\pi^3$

【解答】 $16\pi + 3\pi^3$
4) $\int_C \phi \, ds$

線素: $ds = \sqrt{(-4\sin t)^2 + (4\cos t)^2 + 3^2} \, dt = \sqrt{16+9} \, dt = 5dt$

$\int_C \phi \, ds = 5 \int_0^\pi (16 + 9t^2) \, dt = 5(16\pi + 3\pi^3) = 80\pi + 15\pi^3$

【解答】 $80\pi + 15\pi^3$
問題 6. 放物線および線分に沿う線積分 問6
問題 6 全体指示 スカラー場 $\phi = 4xy$ について，次の $C_1, C_2$ に沿った線積分を求めよ．
1) $C_1: \vec{r}(t) = (t^2, t, 1) \quad (0 \leq t \leq 1)$

$\phi(t) = 4t^3$, \; $ds = \sqrt{(2t)^2 + 1^2 + 0} \, dt = \sqrt{4t^2 + 1} \, dt$

✏️ 置換積分 $u = 4t^2+1$ の詳細手順を見る
$u = 4t^2 + 1 \implies du = 8t \, dt \implies t \, dt = \frac{du}{8}$, \; $t^2 = \frac{u-1}{4}$
$$\int_0^1 4t^3 \sqrt{4t^2 + 1} \, dt = \frac{1}{8} \int_1^5 (u-1)u^{1/2} du = \frac{1}{8} \left[ \frac{2}{5} u^{5/2} - \frac{2}{3} u^{3/2} \right]_1^5 = \frac{25\sqrt{5} + 1}{30}$$
【解答】 $\frac{25\sqrt{5} + 1}{30}$
2) $C_2$: $(0, 0, 1)$ と $(1, 1, 1)$ を結ぶ線分

パラメータ: $\vec{r}(t) = (t, t, 1) \implies \phi(t) = 4t^2, \; ds = \sqrt{2}dt$

$\int_0^1 4t^2 \sqrt{2} \, dt = \frac{4\sqrt{2}}{3}$

【解答】 $\frac{4\sqrt{2}}{3}$
問題 7. ベクトル場の線積分 $\int_C \vec{F} \cdot d\vec{r}$ 問7
問題 7 $\vec{F} = 2x \vec{i} + \sqrt{y} \vec{j} + 2z \vec{k}$，曲線 $C: \vec{r}(t) = t \vec{i} + t^2 \vec{j} + (1 - t) \vec{k} \quad (0 \leq t \leq 1)$ のとき，線積分 $\int_C \vec{F} \cdot d\vec{r}$ を求めよ．

$\vec{F}(t) = 2t \vec{i} + t \vec{j} + 2(1-t) \vec{k}$, \; $d\vec{r} = (\vec{i} + 2t \vec{j} - \vec{k}) dt$

内積: $\vec{F} \cdot \frac{d\vec{r}}{dt} = (2t)(1) + (t)(2t) + (2-2t)(-1) = 2t^2 + 4t - 2$

✏️ 定積分の計算展開を見る
$$\int_0^1 (2t^2 + 4t - 2) \, dt = \left[ \frac{2}{3}t^3 + 2t^2 - 2t \right]_0^1 = \frac{2}{3} + 2 - 2 = \frac{2}{3}$$
【解答】 $\frac{2}{3}$
問題 8. らせんに沿うベクトル線積分 問8
問題 8 ベクトル場 $\vec{F} = -y \vec{i} + x \vec{j} + z(x^2 + y^2) \vec{k}$ における曲線 $C: \vec{r} = a\cos t \vec{i} + a\sin t \vec{j} + bt \vec{k} \quad (0 \leq t \leq 2\pi)$ に沿う線積分 $\int_C \vec{F} \cdot d\vec{r}$ を求めよ．

$x^2+y^2 = a^2 \implies \vec{F}(t) = -a\sin t \vec{i} + a\cos t \vec{j} + a^2 bt \vec{k}$

内積: $\vec{F} \cdot \frac{d\vec{r}}{dt} = a^2 \sin^2 t + a^2 \cos^2 t + a^2 b^2 t = a^2 + a^2 b^2 t$

✏️ 定積分の計算展開を見る
$$\int_0^{2\pi} (a^2 + a^2 b^2 t) \, dt = \left[ a^2 t + \frac{a^2 b^2 t^2}{2} \right]_0^{2\pi} = 2\pi a^2 + 2\pi^2 a^2 b^2$$
【解答】 $2\pi a^2 + 2\pi^2 a^2 b^2 \quad \left( = 2\pi a^2 (1 + \pi b^2) \right)$
問題 9. 円周に沿うベクトル線積分（循環） 問9
問題 9 $\vec{F} = (2x - y - z)\vec{i} + (x + y - z^2)\vec{j} + (3x - 2y + 4)\vec{k}$ とし，$C$ を $xy$ 平面上の原点を中心とする半径 3 の左回りの円とするとき，$\int_C \vec{F} \cdot d\vec{r}$ を求めよ．

$z=0$ より $C: x = 3\cos t, y = 3\sin t, z = 0$

💡 **解法 (グリーンの定理):** $\int_C (F_x dx + F_y dy) = \iint_D \left(\frac{\partial F_y}{\partial x} - \frac{\partial F_x}{\partial y}\right) dx dy = \iint_D (1 - (-1)) dx dy = 2 \times (\pi \cdot 3^2) = 18\pi$

✏️ パラメータ表示による直接の線積分計算を見る
$\vec{F} \cdot \frac{d\vec{r}}{dt} = (6\cos t - 3\sin t)(-3\sin t) + (3\cos t + 3\sin t)(3\cos t) = 9 - 9\sin t \cos t = 9 - \frac{9}{2}\sin 2t$
$$\int_0^{2\pi} \left(9 - \frac{9}{2}\sin 2t\right) dt = [9t]_0^{2\pi} = 18\pi$$
【解答】 $18\pi$
問題 10. ベクトル場 $\vec{F}$ における3種類の線積分 問10
問題 10 全体指示 $\vec{F} = x\vec{i} + 2(x + z)\vec{j} + y\vec{k}$ で曲線 $C$ が原点 $\mathrm{O}$ と点 $\mathrm{P}(1, 2, 2)$ を結ぶ線分のとき，次の線積分を求めよ．

線分のパラメータ表示: $\vec{r}(t) = (t, 2t, 2t) \quad (0 \leq t \leq 1) \implies \vec{F}(t) = t\vec{i} + 6t\vec{j} + 2t\vec{k}, \; ds = 3dt, \; \frac{d\vec{r}}{dt} = (1, 2, 2)$

1) $\int_C \vec{F} \, ds$ （スカラー素片によるベクトル線積分）

$\int_0^1 (t\vec{i} + 6t\vec{j} + 2t\vec{k}) \cdot 3 \, dt = 3(\vec{i} + 6\vec{j} + 2\vec{k}) \left[\frac{t^2}{2}\right]_0^1 = \frac{3}{2}\vec{i} + 9\vec{j} + 3\vec{k}$

【解答】 $\frac{3}{2}\vec{i} + 9\vec{j} + 3\vec{k} \quad \left( = \left(\frac{3}{2}, 9, 3\right) \right)$
2) $\int_C \vec{F} \cdot d\vec{r}$ （内積線積分）

内積: $\vec{F} \cdot \frac{d\vec{r}}{dt} = (t)(1) + (6t)(2) + (2t)(2) = 17t$

$\int_0^1 17t \, dt = \frac{17}{2}$

【解答】 $\frac{17}{2}$
3) $\int_C \vec{F} \times d\vec{r}$ （外積線積分）

外積: $(t\vec{i} + 6t\vec{j} + 2t\vec{k}) \times (\vec{i} + 2\vec{j} + 2\vec{k}) dt = t (8\vec{i} + 0\vec{j} - 4\vec{k}) dt$

$\int_0^1 t (8\vec{i} - 4\vec{k}) \, dt = (8\vec{i} - 4\vec{k}) \left[\frac{t^2}{2}\right]_0^1 = 4\vec{i} - 2\vec{k}$

【解答】 $4\vec{i} - 2\vec{k} \quad \left( = (4, 0, -2) \right)$
