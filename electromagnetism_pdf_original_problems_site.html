スカラー関数の勾配 grad f の計算 (1)

【演習問題】

次のスカラー関数 $f$ の勾配 $\mathrm{grad}\,f$ を求めよ。
(1) $f = e^x \sin y$

【公式・解法の要点】

勾配の定義：$\mathrm{grad}\,f = \nabla f = \left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}\right)$

【ステップ詳細解説】
1. 各変数に関する偏微分を計算：
$$\frac{\partial f}{\partial x} = e^x \sin y, \quad \frac{\partial f}{\partial y} = e^x \cos y, \quad \frac{\partial f}{\partial z} = 0$$
2. したがって勾配ベクトルは：
$$\nabla f = e^x \sin y \vec{i} + e^x \cos y \vec{j}$$

2. したがって：
$$\mathrm{rot}\,\vec{v} = \vec{i} + \vec{j} + \vec{k}$$

【演習問題】

【公式・解法の要点】

【演習問題】

スカラー場 $\phi = x^2+y^2+z^2$ について，$P(1,-1,0)$ と $Q(2,1,2)$ を結ぶ線分 $PQ$ に沿った線積分 $\int_{PQ} \phi ds$ を求めよ。

【公式・解法の要点】

直線パラメータ：$\vec{r}(t) = (1-t)P + tQ = (1+t, -1+2t, 2t) \quad (0 \le t \le 1)$。

【ステップ詳細解説】
1. 速度ベクトル：$\frac{d\vec{r}}{dt} = (1, 2, 2) \implies ds = \sqrt{1^2+2^2+2^2} dt = 3 dt$
2. $\phi(t) = (1+t)^2 + (-1+2t)^2 + (2t)^2 = 9t^2 - 2t + 2$
3. 積分計算：
$$\int_{PQ} \phi ds = \int_0^1 (9t^2 - 2t + 2) \cdot 3 dt = 3 \left[ 3t^3 - t^2 + 2t \right]_0^1 = 3 \times 4 = 12$$

無限長直線電荷および帯電円輪の電場厳密導出

【演習問題】

線密度 $\lambda = 2\times 10^{-9}\,\mathrm{C/m}$ で均一に帯電した無限長直線から距離 $r$ 離れた点における電場の強さ $E(r)$ を求めよ。

【公式・解法の要点】

微小要素 $dx$ が点 $P$ につくる電場 $d\vec{E}$ の対称性を利用。軸に垂直な成分のみが生存する。

【ステップ詳細解説】
1. 微小電荷 $dq = \lambda dx$ の電場垂直成分：
$$dE_\perp = \frac{1}{4\pi\varepsilon_0} \frac{\lambda dx}{r^2+x^2} \cos\theta$$
2. 変数変換 $x = r \tan\theta \implies dx = \frac{r}{\cos^2\theta} d\theta$ を用いて全区間積分：
$$E(r) = \frac{\lambda}{4\pi\varepsilon_0 r} \int_{-\pi/2}^{\pi/2} \cos\theta d\theta = \frac{\lambda}{2\pi\varepsilon_0 r}$$
3. 数値を代入：
$$E(r) \approx \frac{36}{r} \,\mathrm{V/m}$$

ガウスの法則を用いても容易に導出できるが、直接積分法も重要な基盤技術である。

鏡像法（Method of Image Charges）による接地導体平面問題

【演習問題】

接地された無限大導体平面 $z=0$ から距離 $z=h \,\mathrm{m}$ の位置に点電荷 $+q$ がある。導体平面上に誘起される表面電荷密度 $\sigma(x,y)$ および点電荷が受ける引力 $F$ を求めよ。

【公式・解法の要点】

鏡像法の原理：$z=-h$ に置いた仮想の鏡像電荷 $-q$ による合成場として解く。

【ステップ詳細解説】
1. 空間 $z>0$ における電位 $\phi(x,y,z)$：
$$\phi(x,y,z) = \frac{q}{4\pi\varepsilon_0} \left( \frac{1}{\sqrt{x^2+y^2+(z-h)^2}} - \frac{1}{\sqrt{x^2+y^2+(z+h)^2}} \right)$$
2. 表面電荷密度 $\sigma(x,y) = \varepsilon_0 E_z(z=0) = -\frac{q h}{2\pi (x^2+y^2+h^2)^{3/2}}$
3. 静電引力 $F = \frac{1}{4\pi\varepsilon_0} \frac{q^2}{(2h)^2} = \frac{q^2}{16\pi\varepsilon_0 h^2}$$
💡 試験直前チェック・指導ポイント
全誘起電荷を積分すると $\iint \sigma dxdy = -q$ となる。

誘電体境界条件と電界の屈折の法則

【演習問題】

誘電率 $\varepsilon_1$ の媒質1と $\varepsilon_2$ の媒質2の境界において電荷が存在しない。媒質1における電界が法線と角度 $\theta_1$ をなすとき、媒質2における屈折角 $\theta_2$ および電場 $E_2$ を求めよ。

【公式・解法の要点】

境界条件：(1) 電界の接線成分の連続性 $E_{1t} = E_{2t}$。(2) 電束密度の法線成分の連続性 $D_{1n} = D_{2n}$。

【ステップ詳細解説】
1. 2つの境界条件の比をとる：
$$\frac{E_1 \sin\theta_1}{\varepsilon_1 E_1 \cos\theta_1} = \frac{E_2 \sin\theta_2}{\varepsilon_2 E_2 \cos\theta_2} \implies \frac{\tan\theta_1}{\tan\theta_2} = \frac{\varepsilon_1}{\varepsilon_2}$$
2. 媒質2の電場 $E_2$：
$$E_2 = E_1 \sqrt{\sin^2\theta_1 + \left(\frac{\varepsilon_1}{\varepsilon_2}\right)^2 \cos^2\theta_1}$$

スネルの法則とは比の上下関係が逆になる点に注意。
