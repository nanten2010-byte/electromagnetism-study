曲面の面積分とフラックス \(\iint_S \vec{F}\cdot\vec{n} dS\) [No.201]

【演習問題】

平面 $S: 2x + 2y + z = 4 \quad (x \ge 0, y \ge 0, z \ge 0)$ におけるベクトル場 $\vec{F} = x\vec{i} + y\vec{j} + z\vec{k}$ の外向きフラックス $\iint_S \vec{F}\cdot\vec{n} dS$ を求めよ。

【公式・解法の要点】

曲面 $f(x,y,z)=0$ の単位法線ベクトル $\vec{n} = \frac{\nabla f}{|\nabla f|}$。面要素 $dS = \frac{|\nabla f|}{|\partial f/\partial z|} dxdy$。

【ステップ詳細解説】
1. 勾配 $\nabla f = 2\vec{i} + 2\vec{j} + \vec{k}$, $|\nabla f| = \sqrt{9}$
2. 単位法線 $\vec{n} = \frac{2\vec{i}+2\vec{j}+\vec{k}}{\sqrt{9}}$
3. 被積分関数：$\vec{F}\cdot\vec{n} dS = (2x + 2y + z) dxdy = 4 dxdy$
4. 投影領域 $D$ での二重積分：
$$\iint_S \vec{F}\cdot\vec{n} dS = 4 \int_0^2 dx \int_0^{2-\frac{2}{2}x} dy = 8$$

法線ベクトルの向き（外向き・上向き）の指定に常に注意しよう。

平面 $S: 2x + 2y + z = 4 \quad (x \ge 0, y \ge 0, z \ge 0)$ におけるベクトル場 $\vec{F} = x\vec{i} + y\vec{j} + z\vec{k}$ の外向きフラックス $\iint_S \vec{F}\cdot\vec{n} dS$ を求めよ。

【公式・解法の要点】

曲面 $f(x,y,z)=0$ の単位法線ベクトル $\vec{n} = \frac{\nabla f}{|\nabla f|}$。面要素 $dS = \frac{|\nabla f|}{|\partial f/\partial z|} dxdy$。

【ステップ詳細解説】
1. 勾配 $\nabla f = 2\vec{i} + 2\vec{j} + \vec{k}$, $|\nabla f| = \sqrt{9}$
2. 単位法線 $\vec{n} = \frac{2\vec{i}+2\vec{j}+\vec{k}}{\sqrt{9}}$
3. 被積分関数：$\vec{F}\cdot\vec{n} dS = (2x + 2y + z) dxdy = 4 dxdy$
4. 投影領域 $D$ での二重積分：
$$\iint_S \vec{F}\cdot\vec{n} dS = 4 \int_0^2 dx \int_0^{2-\frac{2}{2}x} dy = 8$$
