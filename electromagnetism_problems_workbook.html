第1回演習とレポート

ベクトル解析の基礎（勾配 grad, 発散 div, 回転 rot, 位置ベクトル） （全 9 問）

問 1-1
次のスカラー関数 $f$ の勾配 $\mathrm{grad}\,f$ を求めよ。
1) $f = e^x \sin y$
2) $f = (x^2+y^2+z^2)^2$
3) $f = \frac{1}{2}\ln(x^2+y^2)$
💡 解法のヒント: $\nabla f = \left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}\right)$
🔑 解答・結果:
1) $\nabla f = e^x \sin y \vec{i} + e^x \cos y \vec{j}$
2) $\nabla f = 4(x^2+y^2+z^2)(x\vec{i}+y\vec{j}+z\vec{k})$
3) $\nabla f = \frac{x\vec{i}+y\vec{j}}{x^2+y^2}$
問 1-2
次のベクトル関数 $\vec{g}$ の発散 $\mathrm{div}\,\vec{g}$ を求めよ。
1) $\vec{g} = y^2 e^z \vec{i} + x^2 z^2 \vec{k}$
2) $\vec{g} = x^2\vec{i} + y^2\vec{j} + z^2\vec{k}$
3) $\vec{g} = e^{-xy}\vec{i} + e^{-yz}\vec{j} + e^{-zx}\vec{k}$
💡 解法のヒント: $\nabla\cdot\vec{g} = \frac{\partial g_x}{\partial x} + \frac{\partial g_y}{\partial y} + \frac{\partial g_z}{\partial z}$
🔑 解答・結果:
1) $\mathrm{div}\,\vec{g} = 2x^2 z$
2) $\mathrm{div}\,\vec{g} = 2x + 2y + 2z$
3) $\mathrm{div}\,\vec{g} = -y e^{-xy} - z e^{-yz} - x e^{-zx}$
問 1-3
次式で表されるベクトル $\vec{v}$ について $\mathrm{rot}\,\vec{v}$ を求めよ。
1) $\vec{v} = z\vec{i} + x\vec{j} + y\vec{k}$
2) $\vec{v} = x\vec{i} + yz\vec{j} - (x^2+z^2)\vec{k}$
3) $\vec{v} = (x\vec{i}+y\vec{j}+z\vec{k})(x^2+y^2+z^2)^{-3/2}$
💡 解法のヒント: $\nabla\times\vec{v}$ 行列式を展開する。
🔑 解答・結果:
1) $\mathrm{rot}\,\vec{v} = \vec{i} + \vec{j} + \vec{k}$
2) $\mathrm{rot}\,\vec{v} = -y\vec{i} + 2x\vec{j} - z\vec{k}$
3) $\mathrm{rot}\,\vec{v} = \vec{0}$ （中心力場は無回転）
問 1-4
$\vec{r} = x\vec{i}+y\vec{j}+z\vec{k}, r=|\vec{r}|$ とするとき，次を求めよ。
1) $\nabla r$, 2) $\nabla \frac{1}{r}$, 3) $\nabla r^n$ ($n$:実数), 4) $\nabla \ln r$
💡 解法のヒント: 合成関数の微分 $\nabla f(r) = f'(r)\frac{\vec{r}}{r}$ を利用する。
🔑 解答・結果:
1) $\frac{\vec{r}}{r}$
2) $-\frac{\vec{r}}{r^3}$
3) $n r^{n-2} \vec{r}$
4) $\frac{\vec{r}}{r^2}$
問 1-5
点 $(x,y,z)$ の位置ベクトルを $\vec{r}, r=|\vec{r}|$ とするとき，以下を求めよ。
1) $\nabla \cdot (\vec{r}/r)$
2) $\nabla \cdot (\vec{r}/r^3)$
💡 解法のヒント: 積の微分公式 $\nabla\cdot(\phi \vec{A}) = \nabla\phi \cdot \vec{A} + \phi (\nabla\cdot\vec{A})$ を適用する。
🔑 解答・結果:
1) $\frac{2}{r}$
2) $0$ （原点以外の領域で発散ゼロ）
問 1-6
$\varphi = xyz, \vec{A} = x^2 yz \vec{i} + xy^2 z \vec{j} - xyz^2 \vec{k}$ について，次を求めよ。
1) $\nabla \varphi$, 2) $\nabla \cdot \vec{A}$, 3) $\Delta \varphi$, 4) $\nabla \cdot (\varphi \vec{A})$, 5) $\vec{A} \cdot \nabla \varphi$
💡 解法のヒント: スカラー積およびラプラシアン $\Delta = \nabla^2$ の計算を行う。
🔑 解答・結果:
1) $yz\vec{i} + xz\vec{j} + xy\vec{k}$
2) $2xyz$
3) $0$
4) $3x^2 y^2 z^2$
5) $x^2 y^2 z^2$
問 1-7
$\vec{A} = x^2 z \vec{i} + yz^2 \vec{j} - 2xyk \vec{k}, \vec{B} = 2y^2 \vec{i} - 3yz \vec{j} + zx \vec{k}, \varphi = x^2 + 2yz$ について，次を求めよ。
1) $\vec{A} \times \nabla \varphi$
2) $(\nabla \times \vec{A}) \times \vec{B}$
3) $\vec{B} \cdot (\nabla \times \vec{A})$
💡 解法のヒント: 回転 $\nabla\times\vec{A}$ を先に計算してから外積・内積をとる。
🔑 解答・結果:
1) $(2y^2 z^2 + 4xyz)\vec{i} - (2x^2 yz + 4x^2 y)\vec{j} + (2x^2 z^2 - 2xy^2 z)\vec{k}$
2) $(2xyz + x^3 z)\vec{i} + (2x^2 z + 2xyz^2)\vec{j} + (6xyz + 6y^2 z^2 - 4y^3 - 2x^2 y^2)\vec{k}$
3) $-4xy^2 - 4y^3 z - 6y^2 z - 3x^2 yz$
問 1-8
つるまき線 $C: \vec{r}(t) = 3\cos t \vec{i} + 3\sin t \vec{j} + 4t \vec{k} \quad (0 \le t \le 2\pi)$ において：
1) つるまき線 $C$ の単位接線ベクトル $\vec{u}$ を求めよ。
2) $0 \le t \le 2\pi$ の部分の曲線の長さ $s$ を求めよ。
💡 解法のヒント: 接線ベクトル $\vec{r}'(t)$ とそのノルム $|\vec{r}'(t)| = \sqrt{3^2+4^2} = 5$。
🔑 解答・結果:
1) $\vec{u} = -\frac{3}{5}\sin t \vec{i} + \frac{3}{5}\cos t \vec{j} + \frac{4}{5} \vec{k}$
2) $s = \int_0^{2\pi} 5 dt = 10\pi$
問 1-9
曲面 $\vec{r} = a\sin u\cos v\vec{i} + a\sin u\sin v\vec{j} + a\cos u\vec{k} \quad (0 \le u \le \frac{\pi}{2}, 0 \le v \le 2\pi, a>0)$ において：
1) 曲面 $\vec{r}$ は原点を中心とする半径 $a$ の上半球面 $x^2+y^2+z^2=a^2, z\ge 0$ を表すことを確かめよ。また，曲面を $z=z(x,y)$ の形に表せ。
2) 曲面 $\vec{r}$ の単位法線ベクトルを求めよ。
3) 曲面 $\vec{r}$ の面積を求めよ。
💡 解法のヒント: $x^2+y^2+z^2=a^2$, 面積要素 $dS = a^2 \sin u du dv$。
🔑 解答・結果:
1) $z = \sqrt{a^2-x^2-y^2} \quad (x^2+y^2 \le a^2)$
2) $\vec{n} = \sin u\cos v \vec{i} + \sin u\sin v \vec{j} + \cos u \vec{k}$
3) $S = \int_0^{2\pi} dv \int_0^{\pi/2} a^2 \sin u du = 2\pi a^2$

第2回演習とレポート

線積分と仕事・保存力場 （全 10 問）

問 2-1
曲線 $C$ が弧の長さ $s$ によって次式で表されるとき，円弧の上で $\phi = 2xy^2$ を積分せよ。
$\vec{r}(s) = \cos s \vec{i} + \sin s \vec{j} \quad (0 \le s \le \frac{\pi}{2})$
💡 解法のヒント: $x=\cos s, y=\sin s$ を代入して $s: 0 \to \pi/2$ で積分する。
🔑 解答・結果:
$\int_C \phi ds = \int_0^{\pi/2} 2\cos s \sin^2 s ds = \left[ \frac{2}{3}\sin^3 s \right]_0^{\pi/2} = \frac{2}{3}$
問 2-2
$C$ が $xy$ 平面上の直線 $y=2x$ を $A(-1,-2,0)$ から $B(1,2,0)$ まで区切った線分であるとき，$\int_C xy^3 ds$ を求めよ。
💡 解法のヒント: $x=t, y=2t \implies ds = \sqrt{1+2^2} dt = \sqrt{5} dt \quad (-1 \le t \le 1)$。
🔑 解答・結果:
$\int_{-1}^1 t (2t)^3 \sqrt{5} dt = 8\sqrt{5} \left[ \frac{t^5}{5} \right]_{-1}^1 = \frac{16\sqrt{5}}{5}$
問 2-3
スカラー場 $\phi = x^2+y^2+z^2$ について，下記を計算せよ。
1) $P(1,-1,0)$ と $B(2,1,2)$ を結ぶ線分 $PQ$ に沿った線積分 $\int_{PQ} \phi ds$
2) 1) において、原点 $O$ を経由した折れ線 $PO, OQ$ に沿った線積分 $\int_{POQ} \phi ds$
💡 解法のヒント: 線分の媒介変数表示 $\vec{r}(t) = \vec{r}_0 + t(\vec{r}_1-\vec{r}_0) \quad (0 \le t \le 1)$。
🔑 解答・結果:
1) $\int_{PQ} \phi ds = 12$
2) $\int_{PO} \phi ds + \int_{OQ} \phi ds = \frac{2\sqrt{2}}{3} + 9$
問 2-4
スカラー場 $\phi = 2xz$ について，曲線 $C: \vec{r}(t) = \cos t \vec{i} + \sin t \vec{j} + t \vec{k} \quad (0 \le t \le \pi)$ に沿った線積分 $\int_C \phi ds$ を求めよ。
💡 解法のヒント: $ds = \sqrt{(-\sin t)^2+\cos^2 t+1} dt = \sqrt{2} dt$。
🔑 解答・結果:
$\int_0^{\pi} (2t\cos t) \sqrt{2} dt = 2\sqrt{2} [t\sin t + \cos t]_0^{\pi} = -4\sqrt{2}$
問 2-5
スカラー場 $\phi = x^2+y^2+z^2$ について，曲線 $C: \vec{r} = 4\cos t \vec{i} + 4\sin t \vec{j} + 3t \vec{k} \quad (0 \le t \le \pi)$ に沿った次の線積分を求めよ。
3) $\int_C \phi dt$
4) $\int_C \phi ds$

🔑 解答・結果:
3) $16\pi + 3\pi^3$
4) $80\pi + 15\pi^3$
問 2-6
スカラー場 $\phi = 4xy$ について，次の $C_1, C_2$ に沿った線積分を求めよ。
1) $C_1: \vec{r}(t) = (t^2, t, 1) \quad (0 \le t \le 1)$
2) $C_2: (0,0,1)$ と $(1,1,1)$ を結ぶ線分
💡 解法のヒント: $C_1: ds = \sqrt{4t^2+1} dt$、$C_2: \vec{r}(t)=(t,t,1) \implies ds = \sqrt{2} dt$。

問 2-7
$\vec{F} = 2x\vec{i} + \sqrt{y}\vec{j} + 2z\vec{k}$, 曲線 $C: \vec{r}(t) = t\vec{i} + t^2\vec{j} + (1-t)\vec{k} \quad (0 \le t \le 1)$ のとき，線積分 $\int_C \vec{F}\cdot d\vec{r}$ を求めよ。

🔑 解答・結果:
$\int_0^1 \left( 2t(1) + t(2t) + 2(1-t)(-1) \right) dt = \int_0^1 (2t^2+4t-2) dt = \frac{2}{3}$
問 2-8
次のベクトル場 $\vec{F}$ における曲線 $C$ に沿う線積分 $\int_C \vec{F}\cdot d\vec{r}$ を求めよ。
$\vec{F} = -y\vec{i} + x\vec{j} + z(x^2+y^2)\vec{k}$

問 2-9
$\vec{F} = (2x-y-z)\vec{i} + (x+y-z^2)\vec{j} + (3x-2y+4)\vec{k}$ とし，$C$ を $xy$ 平面上の原点を中心とする半径 3 の左回りの円とするとき，$\int_C \vec{F}\cdot d\vec{r}$ を求めよ。

$\vec{F} = x\vec{i} + 2(x+z)\vec{j} + y\vec{k}$ で曲線 $C$ が原点 $O$ と点 $P(1,2,2)$ を結ぶ線分のとき，次の線積分を求めよ。

$\frac{149\pi}{120}$
