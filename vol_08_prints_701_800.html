ポアソン方程式 \(\Delta\phi = -\rho/\varepsilon_0\) と静電エネルギー演習 [No.701]

【演習問題】

領域 $0 \le x \le d$ において電荷密度が $\rho(x) = \rho_0 \sin\left(\frac{\pi x}{d}\right)$ で与えられている。両端 $x=0, x=d$ で電位 $\phi=0$ となる解 $\phi(x)$ および静電エネルギー密度 $u(x)$ を求めよ。

【公式・解法の要点】

1次元ポアソン方程式：$\frac{d^2\phi}{dx^2} = -\frac{\rho(x)}{\varepsilon_0}$。

【ステップ詳細解説】
1. ポアソン方程式を2回積分：
$$\phi(x) = \frac{\rho_0 d^2}{\pi^2 \varepsilon_0} \sin\left(\frac{\pi x}{d}\right) + C_1 x + C_2$$
2. 境界条件 $\phi(0)=0, \phi(d)=0 \implies C_1=0, C_2=0$:
$$\phi(x) = \frac{\rho_0 d^2}{\pi^2 \varepsilon_0} \sin\left(\frac{\pi x}{d}\right)$$
3. エネルギー密度 $u(x) = \frac{1}{2} \varepsilon_0 E^2 = \frac{\rho_0^2 d^2}{2\pi^2 \varepsilon_0} \cos^2\left(\frac{\pi x}{d}\right)$

微分方程式の任意定数は必ず境界条件から一意に決定すること。

ポアソン方程式 \(\Delta\phi = -\rho/\varepsilon_0\) と静電エネルギー演習 [No.793]

【演習問題】

領域 $0 \le x \le d$ において電荷密度が $\rho(x) = \rho_0 \sin\left(\frac{\pi x}{d}\right)$ で与えられている。両端 $x=0, x=d$ で電位 $\phi=0$ となる解 $\phi(x)$ および静電エネルギー密度 $u(x)$ を求めよ。

【公式・解法の要点】

1次元ポアソン方程式：$\frac{d^2\phi}{dx^2} = -\frac{\rho(x)}{\varepsilon_0}$。

【ステップ詳細解説】
1. ポアソン方程式を2回積分：
$$\phi(x) = \frac{\rho_0 d^2}{\pi^2 \varepsilon_0} \sin\left(\frac{\pi x}{d}\right) + C_1 x + C_2$$
2. 境界条件 $\phi(0)=0, \phi(d)=0 \implies C_1=0, C_2=0$:
$$\phi(x) = \frac{\rho_0 d^2}{\pi^2 \varepsilon_0} \sin\left(\frac{\pi x}{d}\right)$$
3. エネルギー密度 $u(x) = \frac{1}{2} \varepsilon_0 E^2 = \frac{\rho_0^2 d^2}{2\pi^2 \varepsilon_0} \cos^2\left(\frac{\pi x}{d}\right)$

微分方程式の任意定数は必ず境界条件から一意に決定すること。
